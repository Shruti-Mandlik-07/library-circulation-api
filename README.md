## 📖 About The Project
A full-stack Library Management & Circulation Intelligence platform connected to **DataStax Astra DB (Cassandra)** and powered by **Apache PySpark** big data analytics.

---

## ✨ Features You Can Use On The Website
- 📚 **Book Catalog**: Add new books, search by title/author, and view real-time stock availability.
- 🔄 **Circulation Desk**: Issue/borrow books to readers, track 14-day due dates, and return books with 1 click to restock inventory.
- 👥 **Who Issued Books (Reader Analytics)**: Live interactive chart showing who currently holds books and checkout history per member.
- 📊 **Big Data Insights**: Visual charts showing Seattle Public Library checkout trends and material formats.
- ➕ **Input & Store Data**: Direct forms to input and store books, borrow transactions, or analytics records into Astra DB.

---

## 🛠️ Tech Stack
- **Database**: DataStax Astra DB (Apache Cassandra)
- **Big Data Analytics**: Apache PySpark
- **Backend API**: Python Flask, Gunicorn
- **Frontend**: React 19, Recharts, Lucide Icons
- **Deployed on**: Render
